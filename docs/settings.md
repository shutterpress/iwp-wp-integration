# Plugin Settings

**InstaWP → Settings** controls the API key, selected team, integration enablement, automatic site creation, delayed credential release, and customer cache purging. API settings and standalone snapshot tools use the same shared client.

Disabling automatic site creation skips new paid-order processing. Disabling the integration also blocks customer provisioning and site-management actions. Deferred purchases already recorded can be completed when the integration is enabled.

With delayed credentials enabled, customers see their site status but cannot see the username, password or magic login link until an administrator uses **Send Credentials** in **InstaWP → Sites**. Use the FluentCart product integration feed to configure snapshots, plans, expiry and deferred setup.
