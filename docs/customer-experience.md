# Customer Experience

After payment, the FluentCart thank-you page shows site status, links and available credentials. Deferred products show an optional WordPress admin username and subdomain form. InstaWP generates the password. Reload the page shortly after requesting a site to view provisioning progress.

The account shortcode `[iwp_fluentcart_sites]` shows orders associated with the customer's verified WordPress account. Guest access requires the FluentCart receipt `order_hash`, which acts as a private credential. Never publicly share that link or cache personalized portal/thank-you pages.

Delayed credential release applies to both the thank-you page and the account portal. Cache and domain actions are available for ready sites, subject to store settings and hosting-plan availability.
