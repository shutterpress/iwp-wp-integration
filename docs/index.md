# InstaWP for FluentCart

This fork provisions InstaWP sites from FluentCart purchases. It does not load or require WooCommerce.

Start with [Getting Started](getting-started.md), then configure [product feeds](fluentcart-products.md). See [Orders & Site Creation](orders-and-site-creation.md), [Customer Experience](customer-experience.md), and [Subscriptions](subscriptions.md) for the purchase lifecycle.
