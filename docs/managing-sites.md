# Managing Sites

**InstaWP → Sites** lists tracked sites and their creation status, credentials, hosting plan and source. FluentCart order links open the native FluentCart order screen. WordPress administrators can refresh status, release/email credentials, or move sites to Trash.

Customers can view their own sites using `[fcip_sites]` or a FluentCart receipt link. Ready sites have WordPress admin login links. Customers can clear cache when enabled globally and map a primary custom domain for sites with a hosting plan. Each action verifies order access and that the site belongs to that order.

Sites are stored in this plugin’s own `fcip_sites` table and associated with FluentCart orders.
