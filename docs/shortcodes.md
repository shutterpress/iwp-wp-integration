# Shortcodes

`[iwp_fluentcart_sites]` displays the current customer's purchased sites and deferred setup forms. `[iwp_onboarding]` is an alias for the FluentCart portal. Guests use an `order_hash` receipt link; signed-in customers see their own orders.

The existing `[iwp_site_creator]` standalone snapshot creation shortcode remains available. Its configuration, API client, demo expiry and site tracking are independent of cart provisioning. Do not use the retired cart dashboard or checkout field scripts.
