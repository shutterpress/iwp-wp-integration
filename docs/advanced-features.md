# Advanced Features

Product feeds support FluentCart variation conditions, permanent and temporary sites, and deferred post-payment username/subdomain collection. Credentials, task tracking, API caching, team selection and standalone demo creation use the existing InstaWP core.

Order associations live in FluentCart metadata, not WordPress product-variation or order posts. The `iwp_sites.source` value is `fluentcart`. Keep WordPress cron enabled for asynchronous provisioning. The fork's updater checks releases from `shutterpress/iwp-wp-integration`.
