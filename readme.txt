Provision InstaWP sites from FluentCart product purchases.

== Description ==
Configure your InstaWP API key in InstaWP Settings, then add an InstaWP feed on a FluentCart product's Integrations tab. Select snapshots, plans, expiry and optional post-payment setup. Use [fcip_sites] on an account page. See README.md and docs for lifecycle behavior and staging acceptance checks.
